# AutoStock AI

## AI-Based Automobile Spare Parts Stockout Prediction and Supply Disruption Management System

### Overview
AutoStock AI analyzes automobile spare-parts inventory and historical sales data to identify stockout risks, forecast demand, and support inventory planning.

### Objectives
- Analyze spare-parts inventory.
- Identify potential stockout risks.
- Explore historical sales patterns.
- Forecast future demand.
- Recommend actions for supplier disruptions.

### Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- SQLite
- Git and GitHub

### Dataset

The project uses Python-generated synthetic inventory and sales data, along with a synthetic Kaggle supply-chain dataset, for development, analysis, and testing. No real company data is used.
