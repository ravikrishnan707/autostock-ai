# AutoStock AI

## AI-Based Automobile Spare Parts Stockout Prediction and Supply Disruption Management System

### Overview
AutoStock AI analyzes automobile spare-parts inventory and historical sales data to identify stockout risks, forecast demand, and support inventory planning.

### Objectives
- Analyze spare-parts inventory.
- Identify potential stockout risks.
- Explore historical sales patterns.
- Forecast future demand.
- Recommend actions for supplier disruptions.

### Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- SQLite
- Git and GitHub

### Dataset
The project currently uses synthetic inventory and sales data for development and testing. No real company data is used.

### Project Roadmap
1. Foundation and Data Engineering
2. Data Analysis and Feature Engineering
3. Stockout Prediction
4. Demand Forecasting
5. Supplier Disruption and Recommendations
6. Backend and Dashboard
7. Testing, Deployment and Documentation
